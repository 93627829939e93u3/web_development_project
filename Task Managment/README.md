# Task Management Web Application

A full-stack Task Management Web Application built using **HTML, CSS, JavaScript**, **Python (Flask)**, and **SQLite**. This project helps users organize their daily tasks, track progress, and manage productivity through a simple, responsive, and user-friendly interface.

---

## 🚀 Features

* Add new tasks with title, description, and due date
* Edit existing tasks
* Delete tasks
* Mark tasks as completed or pending
* View all tasks in a clean dashboard
* Persistent data storage using SQLite
* Responsive UI for desktop and mobile

---

## ⚙️ Installation & Setup

1. **Clone the repository**

```bash
git clone https://github.com/93627829939e93u3/web_development_project.git
cd web_development_project
cd "Task Managment"
```

2. **Create a virtual environment (optional but recommended)**

```bash
python -m venv venv
source venv/bin/activate  # For Linux/Mac
venv\Scripts\activate     # For Windows
```

3. **Install dependencies**

```bash
pip install flask,sqlite3
```

4. **Run the application**

```bash
python app.py
```

5. **Open in browser**

Visit: `http://127.0.0.1:5000/` (after running from the Task Managment subfolder)

## 🗄️ Database

* The project uses **SQLite** as the database.
* Task data is stored in `database.db`.
* Tables are auto-created when the app runs for the first time.
